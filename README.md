# Bubbly

## First IOS app!

## Description
Bubbly is an app that reminds its user to hydrate throughout the day.

## Features
* Select start and end times in the day to control what times you'll be reminded to hydrate throughout the day.
* Select the interval at which you'd like to be reminded to hydrate. For example, if the interval is set to 10 minutes, the user will be reminded to hydrate to hydrate every 10 minutes throughout the set start and end times.
* Automatically schedules reminders for the next day so you never have to set the reminder settings once you've set them!
